**Curio** 是给 AI 用的设计风格库。每一种风格——包豪斯这样的流派、Stripe 这样的品牌、北斋浮世绘这样的传统——都写成一份 AI 读得懂、用得上的 `DESIGN.md`：配色、字体、间距、组件，还有让它“像那么回事”的规矩。

**这个 skill** 把其中 105 套装进你的 AI，再附一份使用指南（`SKILL.md`），教它怎么用好。你说要做什么：PPT、落地页、海报、报告、邮件；长什么样，交给风格。

## 安装

**Claude Code、Codex、Cursor、OpenCode 等 75 种以上的 agent**

```bash
npx skills add designbycurio/curio-design-skill -g
```

**Claude Code 手动安装**

```bash
git clone --depth 1 https://github.com/designbycurio/curio-design-skill.git ~/.claude/skills/curio
```

**不装也能用**：在 [`designs/`](designs/INDEX.md) 里挑一套，把文件内容复制给 ChatGPT、Claude、Kimi 或任何聊天窗口，告诉它要做什么。

装好以后直接说。提到 Curio 或风格名，skill 就会接手：

> 用 Curio 包豪斯做一份 10 页的融资 PPT，讲我的气候科技项目。
>
> 用孟菲斯风格做 6 张小红书卡片，讲创业的 5 个教训。
>
> 用 Stripe 2024 的风格写一封产品发布邮件。

AI 会读这套风格和 `SKILL.md`，把你要的东西做成一个 HTML 文件。

## 怎么运作

```
designs/<风格>.md   长什么样：配色、字体、间距、组件、该做与不该做
        +
SKILL.md           怎么用：读法，以及每份产出都要守的规矩
        =
你要的 PPT、网页、海报或邮件，换上这套风格
```

skill 不替你决定做成什么形态。要 newsletter 就给 newsletter，要看板就给看板：形态跟着你的需求走，长相跟着风格走。[`examples/`](examples/README.md) 里有 PPT、落地页、海报、社交卡片的排版参考，可看可不看。

- 积分包一次性购买，永不过期，没有订阅

想让 AI 自己翻整座库？用 MCP 接上：**[curio-mcp-extension](https://github.com/designbycurio/curio-mcp-extension)**。

```
curio-design-skill/
├── SKILL.md              skill 本体：读法 + 通用规则
├── designs/              105 套免费风格，每套一份 DESIGN.md

└── MAINTAINING.md        内置风格怎么同步
```
